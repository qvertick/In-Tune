# В лад

Локальное приложение для текста песни, аккордов и репетиции. React + TypeScript + Vite, Python + FastAPI, SQLite. Интерфейс и API работают на одном компьютере. Платных ключей и внешних сервисов для работы нет.

## Уже работает

- Библиотека: создание, поиск, переименование в редакторе, удаление с подтверждением, авторский пример.
- Разделы и строки песни. Вставка многострочного текста создаёт отдельные строки.
- Аккорды над символами текста, отдельная палитра, замена одного вхождения, добавление, удаление, перенос выбором новой позиции. Общая замена показывает число вхождений и требует подтверждения.
- Ввод и конструктор аккордов, включая slash bass. Принимаются `#`/`♯` и `b`/`♭`; в данных используется ASCII, энгармонические написания не объединяются.
- Отмена и повтор последних 100 изменений. Для правок текста также доступны обычные действия поля ввода.
- Автосохранение через 650 мс, состояние сохранения, аварийный черновик браузера при ошибке. При следующем открытии более новый черновик восстанавливается.
- Проверяемый JSON формата v1, импорт отдельной копией. **JSON не содержит MP3**; аудио переносится отдельно.
- Загрузка и хранение MP3 до 50 МиБ, метаданные длительности, настоящий плеер с перемоткой и громкостью.
- Последовательная фоновая очередь, этапы, отмена, восстановление очереди после перезапуска. Анализ создаёт отдельный черновик; исходная песня и ручные правки сохраняются.
- Необязательная локальная транскрипция Whisper tiny на CPU/int8. Без установленной модели задача выдаёт понятную ошибку; редактор и плеер продолжают работать.
- Экспериментальный анализ 24 major/minor-трезвучий без весов модели. Неопределённые интервалы сохраняются без названия, краткие изменения сглаживаются. Это грубый черновик гармонии, не восстановление аппликатур или боя.
- Чтение с выбором строки и раздела, размером текста; метроном Web Audio; микрофон по явному нажатию, выбор входа и уровень сигнала.

Добавлены **«По оригиналу»** и **«Следовать за мной»**: подсветка движется по временной карте независимо от ответов распознавания. В первом режиме микрофон не корректирует часы, во втором локальный потоковый Vosk осторожно поправляет позицию и скорость. Оригинал по умолчанию молчит. Русская модель уже установлена; новые веса для этого обновления не нужны.

## Подготовить и проверить сопровождение

1. Запустите `python run.py`, откройте http://127.0.0.1:8000 и обновите вкладку **Ctrl+F5**.
2. Откройте песню с готовым текстом. Если временные отметки уже есть, переходите к исполнению. Иначе прикрепите исходный MP3; в блоке «Черновик из аудио» выберите **«Временная карта известного текста · Vosk» → «Начать анализ»**. Требуется FFmpeg. По окончании нажмите **«Открыть отдельную копию»**. Исходная песня и ручные правки сохраняются.
3. Нажмите **«Исполнять»**, выберите строку. Внизу раскройте **«Проверка разметки выбранной строки»**: прослушайте участок, поправьте начало/конец строки или каждого слова, нажмите **«Сохранить разметку строки»**. Кнопки «Из плеера» берут текущее время записи. При пропущенных словах используйте только границы строки. Статус сохранения показан рядом.
4. Выберите **«По оригиналу»**, скорость (например, 0,8 или 1,2), при желании отсчёт, нажмите **«Запустить сопровождение»**. Для проверки с записью есть отдельный флажок **«Слушать оригинал при проверке»**. Пауза сохраняет позицию; нажатие на строку задаёт новое место. У слов без подходящих отметок нет фиктивной точной подсветки.
5. Выберите **«Следовать за мной»**, язык и стартовую строку, затем **«Начать: следовать за мной»** и разрешите микрофон. Для этого режима разметьте все вокальные строки: неизвестный участок нельзя считать проигрышем. Оригинал не воспроизводится.
6. Сначала прочитайте текст без гитары, затем спойте без инструмента и только потом повторите с акустикой. В ожидаемом проигрыше движение продолжается как прогноз. Если голос не подтверждает место в вокальном участке, после шести секунд карты прогноз приостанавливается. Для восстановления нажмите строку или спойте узнаваемую фразу. **«Стоп»** освобождает микрофон и останавливает обработку.

Без временной карты сохранён прежний режим **«Следовать за голосом»**: он не требует MP3, но переключает только строки после распознавания окна 3,2 секунды. Это запасной режим с задержкой, а не новое плавное сопровождение.

Скрываемая диагностика показывает позицию/скорость часов, последнюю подтверждённую позицию, фразу, возраст конца обработанного аудио, вычисление, поправку и словесное состояние. Нет выдуманных процентов уверенности. Проверено на синтезированной речи; живое пение с гитарой пока не проверено. Подробности и воспроизводимый замер: [docs/TIMELINE.md](docs/TIMELINE.md).

Если модели нужного языка нет, экран покажет точную команду. Выполните из корня проекта:

```powershell
# Выберите только один нужный язык: ru, uk или en.
powershell -ExecutionPolicy Bypass -File .\install-follow.ps1 -Language uk
```

Скрипт устанавливает Vosk и **только выбранную** модель, затем сообщает о завершении. После установки перезапустите приложение. Официальные размеры архивов: русский small-ru-0.22 — около 45 МБ, украинский small-uk-v3-nano — 73 МБ, английский small-en-us-0.15 — 40 МБ. Точный скачанный русский архив: **46 236 750 байт**. Windows-пакет Vosk — около 14 МБ плюс зависимости; распакованные модели занимают больше места. Код и выбранные модели: Apache 2.0, см. [официальный каталог](https://alphacephei.com/vosk/models) и [лицензию Vosk](https://github.com/alphacep/vosk-api/blob/master/COPYING). При обычном запуске загрузок нет.

Подробности реализации, измерения и ограничения: [docs/VOICE_FOLLOW.md](docs/VOICE_FOLLOW.md).

## Запуск на этом компьютере

Из корня проекта в PowerShell:

```powershell
python run.py
```

Откройте адрес, напечатанный командой, обычно http://127.0.0.1:8000. Если порт занят, выбирается свободный из 8000–8019. **Остановка: Ctrl+C** в том же окне. Сервер отдаёт готовый frontend, поэтому второй процесс для обычной работы не нужен. Команда не завершает чужие процессы и не открывает доступ в локальную сеть.

Можно также запустить `powershell -ExecutionPolicy Bypass -File .\start.ps1`. Это параметр только запуска текущего скрипта, системная политика не меняется.

Фоновый запуск без отдельного окна: `python run.py --background`. Его остановка: `python run.py --stop`. Завершение дожидается освобождения ресурсов текущего анализа; чужие процессы не затрагиваются. Журнал: `data/server.log`. Повторный запуск сообщает адрес уже работающего экземпляра.

## Установка с нуля

Нужны Windows, Python 3.12+ и Node.js 22+; для frontend используется pnpm 11.25.0. При отсутствии pnpm установите его через пакетный менеджер Node: `npm install --global pnpm@11.25.0`.

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
.\.venv\Scripts\python.exe run.py
```

Активация окружения не нужна. Скрипт создаёт `.venv`, устанавливает закреплённые Python-зависимости, frontend по `pnpm-lock.yaml` и собирает интерфейс. Интернет нужен при установке пакетов. Модели скрипт не скачивает. В текущей рабочей среде базовые Python-пакеты уже изолированы в `backend/.deps`; `run.py` умеет их находить.

Ручная установка:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
cd frontend
pnpm install --frozen-lockfile
pnpm run build
cd ..
.\.venv\Scripts\python.exe run.py
```

## Разработка и проверки

В первом окне из корня запустите backend:

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Во втором: `cd frontend`, затем `pnpm dev`. Vite сообщает адрес и направляет относительные `/api` на backend. Остановка обоих окон: Ctrl+C.

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
pnpm test
pnpm run build
```

Типы проверяются при сборке. Тесты проверяют привязки, Unicode, многострочную вставку, сериализацию, API, хранение, неверные файлы, очередь, отмену и сохранность ручных данных. Проверка реального микрофона и пения требует участия пользователя. Автоматизированная визуальная проверка заблокирована средой управления браузером; адаптивная вёрстка требует дополнительной проверки на реальных устройствах.

## FFmpeg

Для обычного плеера и загрузки MP3 FFmpeg не требуется. Он нужен для анализа. На текущем компьютере найден в PATH.

Проверьте `ffmpeg -version`. Если команды нет, возьмите Windows-сборку по ссылке с [официальной страницы FFmpeg](https://ffmpeg.org/download.html), распакуйте и добавьте каталог `bin` в пользовательский PATH. Затем откройте новое окно PowerShell. Приложение само настройки Windows не меняет. FFmpeg вызывается списком аргументов без shell; пользовательское имя файла не становится командой.

## Необязательная модель текста

Транскрипция не установлена по умолчанию. Сначала установите дополнительные пакеты, затем отдельно скачайте модель:

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-audio.txt
.\.venv\Scripts\python.exe -m backend.providers --install-model --revision d90ca5fe260221311c53c58e660288d3deb8d356
```

Модель требует примерно **78,2 МБ** для четырёх обязательных файлов, без учёта дополнительных пакетов и служебных данных. Размеры и проверенная ревизия приведены в `backend/MODELS.md`. Во время обычного запуска скачивания нет. Каталог: `models/whisper-tiny`. Нужны файлы `model.bin`, `config.json`, `tokenizer.json`, `vocabulary.txt`. Для ручной установки используйте полную совместимую копию [Systran/faster-whisper-tiny](https://huggingface.co/Systran/faster-whisper-tiny). Код faster-whisper и карточка модели указывают MIT; CTranslate2 поддерживает [int8 на CPU](https://opennmt.net/CTranslate2/quantization.html).

Загружается одна модель, она переиспользуется, тяжёлые задания выполняются последовательно. GPU не требуется. До 10 минут аудио на задачу, декодирование ограничено 120 секундами. Отмена распознавания обрабатывается между фрагментами; завершение текущего вычисления может занять время. Forced alignment и отделение вокала не подключены. Отметки слов приблизительные, особенно для пения. Качество русских и украинских песен и задержка на этом ноутбуке ещё не измерены.

## Данные и ограничения

По умолчанию: `data/songs.sqlite3`, `data/jobs.sqlite3`, `data/audio/`. Каталог можно задать **до запуска**:

```powershell
$env:VLAD_DATA_DIR = 'D:\Music\VladData'
python run.py
```

Для резервной копии остановите приложение и скопируйте каталог данных целиком. Экспорт одной песни содержит текст, палитру, привязки и параметры, но не аудиофайл. Аварийные черновики привязаны к браузеру и адресу приложения; экспортируйте важные правки при длительной ошибке сохранения.

Привязки используют ID строки и смещение в Unicode code points. Вставка перед аккордом сдвигает его вправо. При удалении фрагмента содержащиеся в нём привязки остаются в начале удалённого фрагмента. Отмена возвращает прежнее состояние. При изменении текста его старые временные отметки сбрасываются. Перенос аккорда выполняется выбором новой позиции, перетаскивания пока нет.

Ограничения документа: JSON до 2 МиБ, до 200 разделов и аккордов в палитре, 2000 строк, 10000 символов в строке, 20000 вхождений. Несколько вхождений в одном слове и инструментальные строки поддерживаются.

Одновременно используйте один сервер и одну вкладку редактора. Совместное редактирование и разрешение конфликтов между вкладками не реализованы. Работа с телефона по LAN не настроена; микрофону нужен безопасный контекст, localhost либо HTTPS.

Название интерфейса меняется в `frontend/src/config.ts`, затем нужна повторная сборка. Исходные записи, модели, временные файлы и базы исключены из Git.
